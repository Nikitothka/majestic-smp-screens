# Разбор скриншотов СМП — Majestic RP, «Россия Онлайн»

Программа для медиков фракции. Кидаешь скриншоты работы — она сама раскладывает их
по папкам балловой системы, считает баллы, прогресс до повышения и недельный отчёт.
Всё, в чём она не уверена, откладывает на ручную проверку, а не угадывает.

Что она понимает по скриншоту:

- **что сделано** — реанимация, таблетка, вакцина, отменённый вызов (по плашке внизу экрана);
- **когда** — день, ночь или обед 14–15 (по часам в HUD);
- **где** — ГКБ 1, ГКБ 2 «Склиф», мед.отсек АСМП или улица (по интерьеру и миникарте);
- **кого** — номер или имя пациента.

## Установка

1. Поставь [Python 3.11 или новее](https://www.python.org/downloads/).
   При установке отметь галочку **Add python.exe to PATH**.
2. Скачай программу: зелёная кнопка **Code → Download ZIP** на странице репозитория, распакуй.
3. Запусти **`install.bat`**. Он спросит про видеокарту NVIDIA:
   - есть — ответь `y`, будет быстрее (скачается ~2.5 ГБ);
   - нет или не знаешь — просто Enter, поставится лёгкая версия под процессор.
4. Запускай **`run.bat`**.

При первом разборе программа докачает модели распознавания (~150 МБ) — нужен интернет.

## Как снимать

Скриншоты — через оверлей **NVIDIA** (Alt+F1). Они попадают в
`Видео\NVIDIA\Grand Theft Auto V`, и программа сразу берёт их оттуда. Время записано
прямо в имени файла, поэтому ничего переименовывать не надо.

Главное — чтобы в кадре была **плашка действия** («Вы реанимировали #…», «Вы вакцинировали #…»).
Кадр без неё программа не засчитает: так она отличает работу от повторного снимка.

### Какие экраны подходят

Любое разрешение от 1366×768 до 4K, форматы 16:9, 16:10 и 21:9, PNG и JPG. Окно игры
программа находит сама — в том числе если на скрине два монитора.

Проверено на 38 скринах, пересохранённых под разные разрешения:

| Экран | Действие и номер пациента | Часы в игре |
|---|---|---|
| 4K, 1440p | 38 из 38 | 37–38 из 38 |
| 1080p, 1600×900, JPG | 38 из 38 | 35–37 из 38 |
| 1366×768 | действие 38, номер 37 из 38 | 30 из 38 |

Если часы не прочитались, время берётся из имени файла (NVIDIA, Steam) или из времени
создания файла. На маленьком экране чаще будет ручная проверка — но не ошибки.

Скриншоты не через NVIDIA (Steam, AMD, Win+Alt+PrtScn) тоже подходят — добавь их папку
кнопкой «Добавить папку» на вкладке «Разбор».

## Окно программы

### Вкладка «Разбор»

- **Откуда брать** — папка NVIDIA отмечена сама. Другую можно добавить.
- **Куда раскладывать** — по умолчанию `Документы\Отчёты СМП`.
- **Показать, что получится** — ничего не двигает, просто пишет план.
- **▶ Разобрать** — переносит файлы по папкам и собирает отчёт.
- **Разобрать спорные…** — кадры, где программа не уверена: показывает их крупно,
  раскладываешь кнопками категорий.

Если во время игры лагает — поставь галочку «считать на процессоре».

### Вкладка «Отчёт и повышение»

- **Иду на** — выбери ранг (5 → 6, 6 → 7…). Сверху окна будет видно, сколько ПМП,
  вакцин и баллов набрано и сколько не хватает.
- **Держать вакцин про запас** — если хочешь сдавать не впритык.
- **Собрать папку недели** — складывает все кадры недели в одну папку по категориям:
  и уже сданные, и ещё нет. Её и выгружаешь под недельный отчёт. Место на диске
  не тратится: файлы связываются с оригиналами, а не копируются. Работа в обед лежит
  только в «Доп. баллах», один кадр — в одном месте.
- **Отметить сдачу отчёта** — жми сразу после сдачи. Всё снятое до этого момента уедет
  в папку «Сдано …» и **не попадёт в следующий отчёт на повышение**. Недельный при этом
  продолжает считать всю неделю — там сданное тоже учитывается.
- **Папка текущего периода** — можно назвать её по отчёту, например `7-8`.

### Вкладка «Сервис»

Откат последнего разбора, сверка папки на дубли, разметка мест, лог. Нужно изредка.

## Что получается на выходе

```
Отчёты СМП\
  7-8\                                ← текущий, ещё не сданный период
    ПМП день (3 балла)\
    ПМП ночь (5 баллов)\
    ПМП в больнице (1 балл)\
    Отменённый вызов (1 балл)\
    Таблетка ГКБ 1 (1 балл)\  …  Вакцина ГКБ 2 Склиф (2 балла)\
    Доп. баллы (обед 14-15)\
      ПМП в обед\   Вакцины в обед\   Отмены в обед\   Таблетки в обед\
    Замены\
  Сдано 11.09 13-40 — 6-7\            ← уже сданное
  Недельный отчёт\
    неделя 07.09-13.09\               ← вся неделя вместе
  ❓ Проверить вручную\                ← рядом с каждым файлом записка, почему
  _отчёт\
    отчёт.txt   неделя 07.09-13.09.txt   отчёт.xlsx   отчёт.html
```

Каждая папка категории — это одна строка в форме отчёта: выгружаешь папку на Яндекс.Диск,
ссылку и число файлов вписываешь в форму. В каждой папке периода и в папке недели лежит
**«сколько вписывать в форму.txt»**: сколько в какой папке кадров и баллов, а доп. баллы
расписаны по видам работы и по цене — вакцина из Склифа 2 × 2 = 4, из мед.отсека скорой
3 × 2 = 6.

**Один скриншот — одно место.** Работа в обед лежит только в «Доп. баллах», в основной
категории её нет. Не вписывай один и тот же скрин в форму дважды — отчёт вернут.

## Правила подсчёта

Лежат в `medreport/rules.yaml`, общие для всех: баллы по категориям, окна дня, ночи и обеда,
нормативы повышения, замены. Если фракция поменяет правила — правится этот файл.

Несколько вещей, которые программа делает осознанно:

- **«ПМП в больнице»** — только если кадр похож на больничный интерьер. Магазин или тоннель
  тоже «под крышей», но это обычный ПМП за 3 балла.
- **Замены** предлагаются только из излишка сверх норматива и с учётом того, что замена
  стоит баллов: отдаёшь 5 ПМП по 3 балла, получаешь вакцину за 3.
- **Повтор одного случая** — кадр без своей плашки действия считается повтором и не идёт в баллы.

## Если что-то не так

- Кадр лёг не туда — перетащи его руками или через «Разобрать спорные», потом
  «Сервис → Сверить папку».
- Всё сломалось — «Сервис → Откатить последний разбор» вернёт файлы как было.
- Ошибка — «Сервис → Открыть лог», пришли кусок тому, кто дал программу.

## Для тех, кто правит код

```
python -m pip install -r requirements-dev.txt
python -m pytest tests
```

Устройство: `viewport` находит окно игры по логотипу HUD, `extract` читает плашки, часы
и миникарту, `place` определяет место, `score` считает баллы, `sorter` раскладывает
с журналом и откатом, `report` собирает отчёты, `gui` — окно.

`medreport/assets/` — общие эталоны больниц и модели, едут с программой.
`data/` — личное: кэш, настройки, свои эталоны. В репозиторий не попадает.
